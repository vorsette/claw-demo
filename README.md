# 夹夹乐 3D Demo

浏览器里直接玩的 3D 夹娃娃机演示。余额、其他玩家、交易所和拍卖都是模拟数据，存档只保存在访问者自己的浏览器里。

纯静态文件：`index.html` + `assets/`，由 GitHub Pages 提供。

素材：可换装角色、服装、发型、动作来自 Quaternius（CC0）；都市女生 / 机甲战士 / 仿生人为 Mixamo 角色；环境光来自 Poly Haven（CC0）；地砖贴图来自 ambientCG（CC0）。

## /kapsul/ — Kapsul 盲盒 Demo

`kapsul/index.html` 是单文件的盲盒平台演示（用户端 + 后台管理，顶部切换）。全部为模拟数据，存档只保存在访问者自己的浏览器里。商品照片来自 Unsplash。
